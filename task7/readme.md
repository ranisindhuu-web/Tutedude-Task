# Laundry Service Responsive Page

## How to Run

1. Download the project files.
2. Open index.html in a web browser.
3. Resize the browser window to test responsiveness.

## Responsive Design Approach

I used Flexbox to arrange the navbar and hero section. For larger screens the hero content and image are displayed side by side. For mobile screens I changed the flex direction to column so the content stacks vertically.

I added two media query breakpoints:

* 768px for tablets
* 480px for mobile devices

The tablet breakpoint reduces font sizes and image sizes. The mobile breakpoint hides navigation links and changes the hero layout to a vertical arrangement.

## What I Learned

* How Flexbox helps align items easily.
* How media queries can change layouts for different screen sizes.
* How to create separate tablet and mobile designs using CSS breakpoints.
