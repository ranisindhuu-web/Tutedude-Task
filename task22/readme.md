# Project Workspace Landing Page

## Student Project

This project is a simple landing page made using HTML, CSS, JavaScript and Tailwind CSS.

## Features

- Sticky Navigation Bar
- Hero Section
- Gradient Background
- CTA Buttons
- Dashboard Preview
- Floating Information Cards
- Fixed Chat Widget

## Technologies Used

- HTML
- CSS
- JavaScript
- Tailwind CSS CDN

## How to Run

1. Download all files.
2. Keep the files in the same folder.
3. Open `index.html` in your browser.
