# Task 8 - CSS Hover Effects

## Description

This project demonstrates CSS hover effects using transforms and transitions.

## Concepts Learned

* Hover pseudo class (:hover)
* Transform property
* Scale effect
* Rotate effect
* Transition property

## How to Run

1. Open the project folder.
2. Open index.html in a browser.
3. Move the mouse over the buttons to see the hover effects.

## Challenges

At first the hover effect changed instantly and looked rough. I learned that the transition property can make the animation smoother. I also experimented with different scale and rotate values to see how they affect the button.
